📦 Parcel Pilot – Courier Management System

Parcel Pilot is a simple Courier Management System designed to manage courier bookings, customer details, delivery information, and shipment status efficiently. The project provides an easy-to-use system for handling courier operations from booking to delivery.

🚀 Key Features

- 📦 Book and manage courier orders
- 👤 Store customer and receiver details
- 📍 Track courier delivery status
- 🚚 Manage courier and delivery information
- 🔄 Update shipment status
- 🗑️ Delete courier records
- 📋 View all courier bookings
- 🔎 Search and track parcels using a tracking ID

🛠️ Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Java
- Database: MySQL
- Database Connectivity: JDBC
- Architecture: Layered Architecture
- IDE: VS Code / Eclipse

🔄 Project Workflow

Customer → Book Courier → Generate Tracking ID → Store in Database → Update Delivery Status → Track Parcel → Delivery

🎯 Objective

The main objective of Parcel Pilot is to create a simple and organized digital system that makes courier booking, tracking, and management easier and more efficient.
